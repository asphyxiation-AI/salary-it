# Зарплата.IT

Система оценивает условную зарплатную премию за отдельные цифровые компетенции с учетом региона и отрасли.

## Основные возможности (Features)

* Ввод текста вакансии с валидацией поля;
* Прогнозирование точечного значения;
* Прогнозирование диапазона значений;
* Формирование графика вкладов признаков.
